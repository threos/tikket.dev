# Upgrading

1. Pull the current version:

   ```bash
   git pull
   ```

2. Install the dependencies again. This installs the packages that the new version added or changed, and removes the packages that it dropped.

   ```bash
   yarn
   ```

3. Apply the database migrations. Run one of the two commands.

   In a development environment, run:

   ```bash
   yarn workspace @calcom/prisma db-migrate
   ```

   This command can clear your development database in some cases.

   In a production environment, run:

   ```bash
   yarn workspace @calcom/prisma db-deploy
   ```

4. Look for changes to the `.env` variables:

   ```bash
   yarn predev
   ```

5. Start the server. In a development environment, run:

   ```bash
   yarn dev
   ```

   For a production build, run:

   ```bash
   yarn build
   yarn start
   ```

Tikket then runs the new version.
