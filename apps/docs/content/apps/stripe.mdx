# Stripe

With the Stripe app, Tikket collects a payment when a person books an event. The app needs API keys, an OAuth client ID and a webhook. A webhook is a URL that Stripe calls when a payment event occurs.

## Set up Stripe

1. Go to [Stripe](https://stripe.com) and create an account, or log in to an existing one. For testing, activate the "Test-Mode" toggle at the top right of the Stripe dashboard.
2. Open [Stripe API Keys](https://dashboard.stripe.com/apikeys).
3. Copy the key that starts with `pk_` into `NEXT_PUBLIC_STRIPE_PUBLIC_KEY` in the `.env` file.
4. Copy the key that starts with `sk_` into `STRIPE_PRIVATE_KEY` in the `.env` file.
5. Go to [Stripe Connect Settings](https://dashboard.stripe.com/settings/connect) and activate OAuth for Standard Accounts.
6. Add this redirect URL. Replace `<Tikket URL>` with the URL where your Tikket instance runs.

    ```
    <Tikket URL>/api/integrations/stripepayment/callback
    ```

7. Copy your client ID (`ca_...`) into `STRIPE_CLIENT_ID` in the `.env` file.
8. Open [Stripe Webhooks](https://dashboard.stripe.com/webhooks). Add this URL as the webhook for connected applications:

    ```
    <Tikket URL>/api/integrations/stripepayment/webhook
    ```

9. Select all `payment_intent` and `setup_intent` events for the webhook.
10. Copy the webhook secret (`whsec_...`) into `STRIPE_WEBHOOK_SECRET` in the `.env` file.
