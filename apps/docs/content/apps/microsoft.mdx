# Microsoft

The Outlook Calendar app needs an app registration in Azure. The registration gives you a client ID and a client secret for Microsoft Graph, the API of Microsoft 365.

## Get the Microsoft Graph client ID and secret

1. Go to [Azure App Registration](https://portal.azure.com/#blade/Microsoft_AAD_RegisteredApps/ApplicationsListBlade) and select "New registration".
2. Enter a name for your application.
3. Set "Who can use this application or access this API?" to "Accounts in any organizational directory (Any Azure AD directory - Multitenant)".
4. Set the Web redirect URI to this URL. Replace `<Tikket URL>` with the URL where your Tikket instance runs.

    ```
    <Tikket URL>/api/integrations/office365calendar/callback
    ```

5. Copy the "Application (client) ID" into `MS_GRAPH_CLIENT_ID` in your `.env` file.
6. Click "Certificates & secrets" and create a new client secret.
7. Copy the generated secret value into `MS_GRAPH_CLIENT_SECRET` in your `.env` file.
