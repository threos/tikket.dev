# Zoho

Tikket has three Zoho apps: Zoho CRM, Zoho Calendar and Zoho Bigin. Each app needs its own client ID and client secret from the Zoho API Console.

## Get the Zoho CRM client ID and secret

1. Go to the [Zoho API Console](https://api-console.zoho.com/) and sign in to your account, or create a new one.
2. From the API console page, go to "Applications".
3. Click "ADD CLIENT" at the top right and select "Server-based Applications".
4. In the "Client Details" tab, enter the information that you want.
5. Open the "Client Secret" tab.
6. Copy the client ID and the client secret into your `.env` file under these fields:

    ```
    ZOHOCRM_CLIENT_ID
    ZOHOCRM_CLIENT_SECRET
    ```

7. Set the redirect URL for OAuth to this URL. Replace `<Tikket URL>` with the URL where your Tikket instance runs.

    ```
    <Tikket URL>/api/integrations/zohocrm/callback
    ```

8. To use the same OAuth credentials for all data centers, select the "Multi-DC" option under "Settings".
9. Click "Save" or "UPDATE" at the bottom of the page.

You can now add the Zoho CRM app in the Tikket app store.

## Get the Zoho Calendar client ID and secret

1. Go to the [Zoho API Console](https://api-console.zoho.com/) and sign in to your account, or create a new one.
2. Select "Server-based Applications" and set the redirect URL for OAuth to this URL. Replace `<Tikket URL>` with the URL where your Tikket instance runs.

    ```
    <Tikket URL>/api/integrations/zohocalendar/callback
    ```

3. In the "Client Details" tab, enter the information that you want.
4. Open the "Client Secret" tab.
5. Copy the client ID and the client secret into the app keys in the Tikket admin panel at this path:

    ```
    <Tikket URL>/settings/admin/apps
    ```

6. To use the same OAuth credentials for all data centers, select "Multi-DC" under "Settings" in the Zoho API Console.
7. Click "Save" or "UPDATE" at the bottom of the page.

The Zoho Calendar app is now ready. You manage it in Tikket at this path:

```
/settings/my-account/calendars
```

Your Zoho calendar itself is at [https://calendar.zoho.com/](https://calendar.zoho.com/).

If you use more than one calendar with Tikket, enable the toggle that prevents double bookings across calendars. The toggle is at `/settings/my-account/calendars`.

2. Click "ADD CLIENT" at the top right and select "Server-based Applications".
3. Set the redirect URL for OAuth to this URL. Replace `<Tikket URL>` with the URL where your Tikket instance runs.

    ```
    <Tikket URL>/api/integrations/zoho-bigin/callback
    ```

4. Open the "Client Secret" tab.
5. Copy the client ID and the client secret into the `.env.appStore` file under these fields:

    ```
    ZOHO_BIGIN_CLIENT_ID
    ZOHO_BIGIN_CLIENT_SECRET
    ```

6. To use the same OAuth credentials for all data centers, select the "Multi-DC" option under "Settings".

You can now add the Zoho Bigin app in the Tikket app store.
