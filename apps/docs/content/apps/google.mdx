# Google

The Google Calendar app and Login with Google both need OAuth credentials from a Google Cloud project. OAuth is the protocol that lets Tikket access a Google account with the permission of its owner.

## Get the Google API credentials

1. Go to the [Google API Console](https://console.cloud.google.com/apis/dashboard). If your Google Cloud subscription has no project, create one first.
2. In the Dashboard pane, select "Enable APIs and Services".
3. In the search box, type "calendar" and select the Google Calendar API search result.
4. Enable the Google Calendar API.
5. Open the [OAuth consent screen](https://console.cloud.google.com/apis/credentials/consent) from the side pane. Select the app type (Internal or External) and enter the basic app details on the first page.
6. On the Scopes page, select "Add or Remove Scopes". Search for Calendar.event and select the scopes `.../auth/calendar.events` and `.../auth/calendar.readonly`. Then click "Update".
7. On the Test Users page, add the Google accounts that you will use. On the last page, make sure that the details are correct to complete the consent screen configuration.
8. From the side pane, open [Credentials](https://console.cloud.google.com/apis/credentials). Select "Create Credentials", then "OAuth Client ID".
9. Select "Web Application" as the application type.
10. Under "Authorized redirect URIs", add these two URIs. Replace `<Tikket URL>` with the URL where your Tikket instance runs.

    ```
    <Tikket URL>/api/integrations/googlecalendar/callback
    <Tikket URL>/api/auth/callback/google
    ```

11. Google creates the key and returns you to the Credentials page. Under "OAuth 2.0 Client IDs", select the new client ID, then click "Download JSON".
12. Copy the contents of the JSON file. Paste the whole string into `GOOGLE_API_CREDENTIALS` in the `.env` and `.env.appStore` files.
13. In the `.env` file, set this variable. It configures the Google integration as an internal app and restricts login access.

    ```
    GOOGLE_LOGIN_ENABLED=false
    ```

## Add Google Calendar to the Tikket app store

After you add the Google credentials, seed the app store again. The seed adds the Google Calendar app to the app store.

```bash
yarn db-seed
```
