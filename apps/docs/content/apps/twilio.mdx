# Twilio

Twilio is a service that sends SMS messages. Tikket reads the Twilio credentials from the `.env` file.

## Get the Twilio credentials

1. Go to [Twilio](https://www.twilio.com/) and create an account.
2. Click "Get a Twilio phone number" to get a phone number for your account.
3. Copy the Account SID into your `.env` file under this field:

    ```
    TWILIO_SID
    ```

4. Copy the Auth Token into your `.env` file under this field:

    ```
    TWILIO_TOKEN
    ```

5. Copy your Twilio phone number into your `.env` file under this field:

    ```
    TWILIO_PHONE_NUMBER
    ```

6. Add your own sender ID to the `.env` file under this field. If you do not set it, Tikket uses `Tikket` as the sender ID.

    ```
    NEXT_PUBLIC_SENDER_ID
    ```

7. Open "Develop", then "Messaging", then "Services", and create a new messaging service.
8. Enter a name for the messaging service. Any name works.
9. Click "Add Senders" and select "Phone number" as the sender type.
10. Add your Twilio phone number to the messaging service.
11. Leave the other fields as they are. Click "View my new Messaging Service" to complete the setup.
12. Copy the Messaging Service SID into your `.env` file under this field:

    ```
    TWILIO_MESSAGING_SID
    ```

13. In the Twilio dashboard, create a new Verify Service and give it a name.
14. Copy the Verify Service SID into your `.env` file under this field:

    ```
    TWILIO_VERIFY_SID
    ```
