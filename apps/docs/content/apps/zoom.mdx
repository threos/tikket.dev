# Zoom

The Zoom app creates a Zoom meeting for each booking. The app needs a client ID and a client secret from an OAuth app in the Zoom Marketplace.

## Get the Zoom client ID and secret

1. Go to the [Zoom Marketplace](https://marketplace.zoom.us/) and sign in with your Zoom account.
2. At the top right, click "Develop", then "Build App".
3. Under "OAuth", select "Create".
4. Enter a name for your app.
5. Select "User-managed app" as the app type.
6. Deselect the option to publish the app on the Zoom App Marketplace.
7. Click "Create".
8. Copy the client ID and the client secret into your `.env` file under these fields:

    ```
    ZOOM_CLIENT_ID
    ZOOM_CLIENT_SECRET
    ```

9. Set the redirect URL for OAuth to this URL. Replace `<Tikket URL>` with the URL where your Tikket instance runs.

    ```
    <Tikket URL>/api/integrations/zoomvideo/callback
    ```

10. Add the redirect URL to the allow list and enable "Subdomain check". Make sure that the form shows "saved" below it.
11. Skip the basic information about your app. Go to "Scopes" and click "+ Add Scopes". Select the category "Meeting" on the left and select the scope `meeting:write`.
12. Click "Done" to save the scope.

You can now add the Zoom app in the Tikket app store.
