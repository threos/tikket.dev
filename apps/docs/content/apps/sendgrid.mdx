# SendGrid

Tikket uses SendGrid to send email reminders and for its internal sync services. SendGrid needs an API key and one sender address that SendGrid has approved.

## Get the SendGrid API key and sender address

1. Go to [https://signup.sendgrid.com/](https://signup.sendgrid.com/) and create a SendGrid account.
2. Open "Settings", then "API Keys", and create a new API key.
3. Copy the API key into your `.env` file under this field:

    ```
    SENDGRID_API_KEY
    ```

4. Open "Settings", then "Sender Authentication", and complete the single sender verification for one email address.
5. Copy the verified email address into your `.env` file under this field:

    ```
    SENDGRID_EMAIL
    ```
