# Daily

Daily provides Cal Video, the built-in video call app in Tikket. Tikket needs a Daily API key before it can create video rooms.

## Get the Daily API credentials

1. Go to [Daily](https://daily.co) and sign in to your account.
2. In your dashboard, open the "Developers" tab.
3. Copy the API key that the "Developers" tab shows.
4. Paste the API key into `DAILY_API_KEY` in your `.env` file.
5. If you have the Daily Scale Plan, set `DAILY_SCALE_PLAN` to `true` in the `.env` file. The Scale Plan enables features such as video recording.
