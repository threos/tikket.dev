# AWS

This page gives the general steps to deploy Tikket on Amazon Web Services (AWS). The [AWS documentation](https://docs.aws.amazon.com/) describes each AWS service in detail.

## Prerequisites

Before you start, make sure that you have:

- An AWS account.
- Knowledge of the AWS services and the AWS Management Console.
- Access to the Tikket source code at [https://github.com/threos/tikket.dev](https://github.com/threos/tikket.dev).

## Set up the AWS environment

1. If you do not have an AWS account, create one.
2. Log in to the AWS Management Console.

## Create the AWS resources

1. Create an IAM user with the permissions that it needs to deploy and manage the application.
2. Create the services that your deployment needs, such as Amazon EC2 and RDS for PostgreSQL.

## Configure Tikket

1. Clone the Tikket repository to your local environment:

    ```bash
    git clone https://github.com/threos/tikket.dev.git
    ```

2. Update the `.env` file with the details of your AWS resources, such as the database endpoint. The [Installation](/installation) page describes the configuration.

## Deploy on AWS

1. Deploy the Tikket application with an AWS service such as EC2 or Elastic Beanstalk.
2. Connect the RDS instance to the application.
3. Make sure that the application runs and that you can reach it.

## After the deployment

1. Update your DNS records so that your domain points to the AWS deployment.
2. Use the AWS monitoring tools to watch the performance of the application. Scale the resources when the load requires it.

## Recommendations

- Update your deployment when Tikket publishes a new release.
- Follow the security practices that AWS recommends.
