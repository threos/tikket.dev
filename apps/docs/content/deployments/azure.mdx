# Azure

This page gives the general steps to deploy Tikket on Microsoft Azure.

## Prerequisites

Before you start, make sure that you have:

- A Microsoft Azure account.
- Basic knowledge of the Azure services.
- Access to the Tikket source code at [https://github.com/threos/tikket.dev](https://github.com/threos/tikket.dev).

## Set up Azure

1. If you do not have an Azure account, create one.
2. Log in to the Azure Portal.

## Create the Azure resources

1. In the Azure Portal, create a new resource group for your Tikket project.
2. Create the services that your deployment needs, such as Azure App Service and Azure Database for PostgreSQL.

## Configure Tikket

1. Clone the Tikket repository to your local machine:

    ```bash
    git clone https://github.com/threos/tikket.dev.git
    ```

2. Update the `.env` file with the Azure configuration, such as the database connection string. The [Installation](/installation) page describes the configuration.

## Deploy on Azure

1. Deploy the Tikket web application with Azure App Service.
2. Deploy Azure Database for PostgreSQL and connect it to Tikket.
3. Make sure that the application runs after the deployment.

## After the deployment

1. Update your DNS records so that your domain points to the Azure deployment.
2. Use the Azure monitoring tools to watch the performance of the application. Scale the resources when the load requires it.
