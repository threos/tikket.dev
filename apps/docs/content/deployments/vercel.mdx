# Vercel

## Requirements

A Vercel Pro plan is required to deploy this application on Vercel. The free plan limits the number of serverless functions.

You also need a PostgreSQL database that runs somewhere that Vercel can reach. [Supabase](https://supabase.com) offers a free option and [Heroku](https://heroku.com) offers a low-cost option.

## Manual deployment

### Prepare the database on your machine

1. Fork the repository and clone your fork:

    ```bash
    git clone https://github.com/<your-fork>/tikket.dev.git
    ```

2. Copy the `.env.example` file in the repository root to `.env` and fill in your configuration. The [Installation](/installation) page and the [Google](/apps/google) page describe the values.
3. Install the packages with Yarn:

    ```bash
    yarn install
    ```

4. Create the database tables from the Prisma schema. The schema is in `packages/prisma/schema.prisma`.

    ```bash
    yarn workspace @calcom/prisma db-deploy
    ```

5. Open Prisma Studio to view or edit the database content:

    ```bash
    yarn db-studio
    ```

6. Click the `User` model to add a new user record.
7. Fill in the fields and click `Save 1 Record` to create your first user. Encrypt the password with [BCrypt](https://bcrypt-generator.com/) before you paste it.
8. Open a browser at port 3000 on your localhost and log in with the user that you created.

If `yarn install` fails during the deployment on Vercel, use `YARN_ENABLE_IMMUTABLE_INSTALLS=false yarn install` as the install command instead.

### Deploy on Vercel

1. Create a new project on Vercel.
2. Import the project from your fork of the repository.
3. Set the environment variables.
4. Set the root directory to `apps/web`.
5. Override the build command with:

    ```bash
    cd ../.. && yarn build --include-dependencies --no-deps
    ```

6. Click "Deploy".
