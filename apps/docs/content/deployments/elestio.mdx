# Elestio

Elestio does not have a Tikket template. Deploy Tikket from the repository with the general steps below.

## Deploy from the repository

1. Create a new service on Elestio and connect the GitHub repository [https://github.com/threos/tikket.dev](https://github.com/threos/tikket.dev), or your fork of it.
2. Create a PostgreSQL database for Tikket.
3. Set the environment variables. The file `.env.example` in the repository root lists them. At a minimum, set `DATABASE_URL`, `DATABASE_DIRECT_URL`, `NEXTAUTH_SECRET`, `CALENDSO_ENCRYPTION_KEY` and `NEXT_PUBLIC_WEBAPP_URL`.
4. Make sure that the build uses Node.js 18 or newer and Yarn 4.
5. Set the build command to `yarn build` and the start command to `yarn start`. If Elestio builds from a Dockerfile, you can use the `Dockerfile` in the repository root instead.
6. Run the database migrations once against the new database, with `DATABASE_URL` set:

    ```bash
    yarn workspace @calcom/prisma db-deploy
    ```

7. Deploy the service and open the URL that Elestio assigns to it.
