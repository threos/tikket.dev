# GCP

This page describes how to deploy Tikket on Google Cloud Platform (GCP). You create a virtual machine, open its firewall, install Docker, build the Tikket image and start the container.

## 1. Create a virtual machine

1. Open the Google Cloud Platform console at [https://console.cloud.google.com/](https://console.cloud.google.com/).
2. If you do not have a project, open the "Select a project" menu and select "New Project". Enter a name for your project and click "Create".
3. Click the navigation menu icon (three horizontal lines) and select "Compute Engine". Then click "VM instances" in the sub-menu.
4. Click "Create" to create a new virtual machine.
5. Select the machine type that fits your needs. A machine with 2 vCPUs and 2 to 4 GB of RAM is enough.
6. In the "Networking" tab, click "Add network". Select the "Default" network and click "Add".
7. Make sure that the details of the virtual machine are correct, then click "Create".
8. Write down the public IP of the virtual machine. You need it later.

## 2. Open the firewall

Tikket listens on port 3000 inside the Docker container. The virtual machine must accept traffic on this port.

1. Click the navigation menu icon and select "Compute Engine". Then click "VM instances" in the sub-menu.
2. Click the name of your new instance to open its details page.
3. Open the "Firewalls" tab and click "Add firewall rule".
4. Select "Allow all" as the source and the destination. Set the protocol to "tcp" and the port to "3000".
5. Click "Add" to save the rule.

## 3. Install Docker

1. Open a terminal on your local machine and connect to the virtual machine with SSH. The GCP console shows the external IP address or the DNS name of your instance.

    ```bash
    gcloud compute ssh --project=[PROJECT_ID] --zone=[ZONE] [INSTANCE_NAME]
    ```

    Replace `[PROJECT_ID]` with your project ID, `[ZONE]` with the zone of your instance and `[INSTANCE_NAME]` with the name of your instance. You can also use the web-based SSH in the GCP console.

2. On the virtual machine, update the package list and install Docker:

    ```bash
    sudo apt-get update
    sudo apt-get install docker.io
    ```

3. Start the Docker service:

    ```bash
    sudo systemctl start docker
    ```

## 4. Deploy Tikket

Tikket does not publish a Docker image. You build the image from the repository on the virtual machine. The [Docker](/docker) page describes the Docker configuration in detail.

1. On the virtual machine, clone the repository and go into its directory:

    ```bash
    git clone https://github.com/threos/tikket.dev.git
    cd tikket.dev
    ```

2. Copy `.env.example` to `.env` and fill in your configuration:

    ```bash
    cp .env.example .env
    ```

3. Build the Tikket image:

    ```bash
    DOCKER_BUILDKIT=0 docker compose build calcom
    ```

4. Start the Tikket container:

    ```bash
    docker compose up -d calcom
    ```

5. Open a web browser and go to `http://` followed by the public IP of the virtual machine and `:3000`. The Tikket home page opens.

Tikket now runs on Google Cloud Platform.
